Native Dark Mode Awareness

DarkWave detects if a site like GitHub or YouTube already uses dark mode and skips it to prevent double-inverting.

  • ✓ Checks background luminance
  • ✓ Reads color-scheme meta tags
  • ✓ Detects data-theme="dark" attributes

Blacklist

One-Keystroke Blacklist

If any site looks off, blacklist it permanently in one keystroke. DarkWave will never touch it again.

Keyboard Shortcut

Alt + Shift + B

Or use the ✕ button in the popup blacklist panel.

Worth knowing

Two keys, and you're set

Both are shown inside the extension too, using whatever keys Chrome actually assigned you.

Alt Shift D

Turn it on or off

Flips dark mode across every tab at once, without opening the popup. A small toast confirms which way it went.

Alt Shift B

A page looks wrong? Skip that site

Dark mode works by inverting the page, and a few sites fight that — archive viewers, canvas-heavy apps, pages with odd inline styling. One keystroke excludes just that site and reloads it untouched. Press it again to bring DarkWave back.

You never have to choose between one awkward page and the whole extension.
